# Placement MCQ Generator — Claude Skill

## About

The Placement MCQ Generator is a custom Claude Skill designed to help CSE/IT students prepare for technical placement tests.

It generates placement-oriented multiple-choice questions on core Computer Science topics with four options, answer keys, and short explanations.

## Features

- Placement-focused MCQs
- Conceptual questions
- Application-based questions
- Tricky/interview-style questions
- Four options (A, B, C, D)
- Answer key
- Short explanations
- Suitable for technical placement preparation
